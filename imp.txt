# Supabase Dashboard Setup for user auth #

-- Step 1: Add user_id to models table
ALTER TABLE models ADD COLUMN user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE;

-- Step 2: Enable Row Level Security
ALTER TABLE models ENABLE ROW LEVEL SECURITY;

-- Step 3: Each user only sees their own models
CREATE POLICY "user_sees_own_models"
ON models FOR SELECT
USING (auth.uid() = user_id);

-- Step 4: Each user can only insert their own models
CREATE POLICY "user_inserts_own_models"
ON models FOR INSERT
WITH CHECK (auth.uid() = user_id);

-- Step 5: Each user can only delete their own models
CREATE POLICY "user_deletes_own_models"
ON models FOR DELETE
USING (auth.uid() = user_id);

These are just standard numbers that mean:

2xx = Success
  200 → OK (request worked)
  201 → Created (new thing was made)

4xx = Client made a mistake
  400 → Bad Request (wrong data sent)
  401 → Unauthorized (not logged in)
  403 → Forbidden (logged in but no permission)
  404 → Not Found (wrong URL)
  422 → Unprocessable (missing required fields)

5xx = Server made a mistake
  500 → Internal Server Error (your code crashed)

In YOUR project:
  POST /train/     → 200 (training started)
  POST /auth/login → 200 (login success)
  GET /models/xyz  → 404 (model not found)
  Wrong token      → 401 (unauthorized)

*****************************************************************************************

API = a way for two programs to talk

REST API = uses HTTP methods to do actions:
  GET    → fetch/read data
  POST   → create something new
  PUT    → update something
  DELETE → delete something

In YOUR project:
  GET  /models/        → list all models
  POST /train/         → start training
  POST /models/predict → get prediction
  DELETE /models/xyz   → delete a model
